- **`agent-model`** and **`agent/web/`** — the `OperationRow`/`kind` types the catalogue parses (replaced by the `#[action]` derive) and the SvelteKit UI (the conveyor's is Rust, D5).

- **Template CI workflow and `scripts/` beyond `rename.sh`** — the gitops `rust-service.yml` archetype is the authority.
- **`strata_rag` pgvector schema / HNSW / search** — S07's own map.
