## Licence

| path | symbols | what it is | slices |
|---|---|---|---|
| `backend/src/lib/licence-introspect.ts` (402) | `LicenceIdentity`, `looksLikeJwt`, `licencePathEnabled`, `introspectLicenceToken`, `introspectLicenceForRequest`, `isLicenceBearer`, `licenceUser`, `DELEGATION_TENANT_HEADERS`, `delegatingLicenceSubjects`, `resolveDelegatedTenant` | bearer classifier + licences-service introspection | S02 |
| `backend/src/lib/require-fr-license.ts` (133) | `FR_APP_KEY`, `tenantHasFrLicense`, `invalidateFrLicenseCache`, `requireFrLicense` | per-tenant app entitlement gate | S02 |

Shape rule: `looksLikeJwt` is **exactly three non-empty dot-separated parts**; `a..c`, `.b.c`, `a.b.`, two- and four-part strings are not JWT-shaped. A JWT-shaped token that fails verification is a hard 401 and is **never retried** as a licence token. Tokens are `secrets.token_urlsafe(32)` (base64url, no dots), so the shapes cannot collide. `isLicenceBearer` requires non-JWT shape **and** the path configured.

Cache: `CACHE_TTL_MS = 60_000`, `CACHE_MAX_ENTRIES = 1_000`, keyed `sha256(token)`. **Positive results only**; a negative answer is never cached and **evicts** any cached entry so a revocation is seen on the next call. TTL is clipped to token/licence expiry; an already-past expiry means do not cache. `require-fr-license` is a **second, Redis-backed** cache (`fr-license:tenant:<tenantId>`, `config.frLicense.cacheTtlSeconds`), coalesced by `createSingleFlight` and guarded by a `cacheEpoch` so an invalidation cannot write back a stale answer; it **fails closed**. Carry both into S02 (§5.4 of the spec collapses them to one in-process cache — that is a deliberate change).

## Notes and traps

- `capabilities/` holds 88 modern declarations against 548 paths — most of the surface is `frozen`/legacy. Counting `defineCapability` understates fr ~6×.
- The outbound MCP emitter is **not** in `channels/`; it is `domain/engagement/adapters/mcp.ts`. S06a starts there, not at `channels/mcp.ts` (inbound only).
- The licence rule is two caches with different lifecycles (60 s in-process, Redis per tenant). The spec collapses them — a change, not a port.
- **`MCP_EVENTS_URL`, measured live 2026-11-07:** `http://mcp.mcp.svc.cluster.local:8033/api/channels/fr/events` — a literal on the **`fr`** deployment (`kubectl -n fr get deploy -o jsonpath` → `MCP_EVENTS_URL`). It is **not** set on `mcp-external-driver`, whose env carries only `MCP_FR_BASE_URL`, `MCP_FR_CHANNEL_SECRET` and `MCP_N8N_*`. **One marker remains** — what changed in the commits after `6f7c5097` and whether `routes/mcp-webhook.ts` is mounted at the same path. Resolve it in one command: `git -C $HOME/Movies/fr diff --stat 6f7c5097..origin/main -- backend/src/channels backend/src/routes/mcp-webhook.ts backend/src/domain/engagement`. **Default if it is not run:** nothing on the channel path moved — the contract S06a implements is byte-shaped (path, grammar, HMAC, response words), and the emitter/source-map anchors were read from the pinned tree, not from `origin/main`.
