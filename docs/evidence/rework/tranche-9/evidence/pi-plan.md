# Evidence — tranche-9 PI plan output

Composes the published `pi-plan` output for `tranche-9` as a P0-scoped document with `unit` set to the planning period. The `unit` slot is the verifier's period key (`verify-project.py::_published_for_period`), so a plan composed without it is published but invisible to every member's `pi_plan` check. The body carries the seven headings the output standard requires: Objectives, Plan, WSJF order, Capacity and WIP, Evidence, Dependencies, Backlog refinement.
