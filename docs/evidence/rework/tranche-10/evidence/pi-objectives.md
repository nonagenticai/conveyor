# Evidence — tranche-10 PI objectives output

Composes the published `pi-objectives` output for `tranche-10` as a P0-scoped document with `unit` set to the planning period. The body carries the output standard's four headings: Objectives, Business value, Measurement, Evidence. The objectives are the four the tranche-10 exit is judged against, and the measurement section names the receipt and the exit check as the instruments.
