3. The eighteen stage directories are a vocabulary

docs/plans/04-TOOL-ESTATE-INVENTORY.md §2 records the correction: the "w2v stages" are not services. Two are libraries (primitives, shared); the other sixteen are deliverable blueprints — a kind of output and the sequence that produces it. They are the conveyor's project-type vocabulary, not a deployment plan. A project that needs one names the blueprint and the output, not a service to build.

5. Explicit non-reuse

  • The agent platform is a front end over MCP, not a runtime dependency; the conveyor owns its model (D33, docs/SPEC_V2.md §1.2).
  • fr and care-bus are not imported: fr is the project of record in the old estate; the conveyor replaces its work surfaces; care-bus stays a standalone demo (D48).
  • Archived kag components (kag_graph, karma, hirag, kag_orchestrator) must not be bound as tools; a function that needs one is re-homed per docs/SPEC_LEGACY_KAG.md first (docs/SPEC_V2.md §14, R19).
  • No private host, path or credential enters a published output or the public repository; the reuse map names capabilities and boundaries, never infrastructure.
