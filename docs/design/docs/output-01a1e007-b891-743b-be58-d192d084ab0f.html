Outcome

Make the conveyor execute processes, not n8n graphs. A process is an ordered list of steps — an agent task, a computed task, a gate, or a child call — stored as process/process_step (S11's tables, renamed by migration 0035). Every step has a procedure (SOP): definition of ready, definition of done, acceptance criteria and an inspection; the process declares its user-facing outputs.
