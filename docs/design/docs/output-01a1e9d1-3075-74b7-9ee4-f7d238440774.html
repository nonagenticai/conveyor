Dimensions

Scores

Baseline

The baseline is the starting position, measured before the delivery programme changes anything. It is a baseline for growth, not a verdict: SPEC_V2 §8.1 states that the mandatory artefact set grows with the assessed maturity, so the baseline sets the first plateau rather than a ceiling. P0 measured the baseline; it did not raise it.

The milestones are defined in the published assessment. Their attainment is not measured on 2026-11-26, because attainment belongs to the delivery tranches that follow P0's definition.
