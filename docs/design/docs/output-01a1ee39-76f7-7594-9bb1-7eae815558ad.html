Build vs reuse

  • Tool platform — reuse T13. T14 writes catalogue rows, probes and bindings; a second resolver or ledger is out.
  • Contracts — reuse the captured locks. T14 imports documents, not service code; a lock is a specification, so no licence flows with it and Python or GPL code stays out.
  • V1 externals — reuse as the migration seed only. The coding fleet stays its own repository (ADR 0006); the conveyor calls its gateway contract and imports no code.
  • Ops — reuse the declarations and client. One implementation, two declared surfaces.
  • Refused: the nonagenticai_mcp_server runtime (D44), archived kag (R19), n8n and product applications (§11.2). The GPL R sidecar stays isolated behind its owning services; external data licences stay at the services that hold them (D42).
