Benefits map — P0 (retrospective, 2026-11-26)

Benefit paths

The map published on 2026-11-18 at 08:17:53 (01a1e9e0-750d-71b9-8230-177eebe80e95) records each path from project output through capability and operational outcome to benefit or disbenefit and strategic objective. It is the edge set that turns six individually defined benefits into a programme-level claim, and it follows the benefit_link model of SPEC_V2 §8.3.

Dependencies

The map records dependencies between benefits as well as each benefit's dependence on outputs and capabilities. That is what lets a programme review answer which benefit is at risk when a project slips: the slip propagates through the output and capability edges to the named benefit. The P0 record defines the edges; it contains no live at-risk computation dated 2026-11-26.

Benefits at risk

The map's two operational questions are which benefit is put at risk when a project slips, and which operational area must change its practice before delivery creates value. P0 answered both structurally by publishing the paths and the conditions. The count of benefits currently at risk is not measured in the record, and this retrospective does not estimate it.
