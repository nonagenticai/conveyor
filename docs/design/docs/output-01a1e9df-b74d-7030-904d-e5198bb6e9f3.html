Kata — B1 baseline: Auditable decisions

Context

The benefit profile B1 Auditable decisions requires a measured baseline before the programme can claim an improvement (P0 plan §6; SPEC_V2 §8.3). No baseline for this benefit was measured: the programme has no instrument that records the old practice, so the profile states the baseline as not measured and this kata is the system issue that records the missing measurement.

The measure is the decision rate: a decision row for every choice, and a gate that never refuses in a cycle. The method named in the profile is: Count decision rows per run from the action ledger; a refusing gate is a test at the action boundary.

Decision

Measure the baseline while the old practice is still observable, before the transition the benefit depends on. Record the result against the benefit row and update the profile's Performance group from not measured to the measured value. The interim owner is the programme manager; the BCM position is unstaffed (the skills assessment records the gap), and the benefit owner is re-attributed when it is staffed.

Consequences

Until the baseline is measured, B1 cannot claim an improvement, and a tranche review cannot hold the programme to its target. The measurement is a programme task, not a code change; if the instrument itself does not exist, that is a second kata.

Evidence

  • The benefit row B1 and its profile document (P0).
  • The measurement method above, and the owner's record.
  • The tranche review that accepts the measured baseline.
