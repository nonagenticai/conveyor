Outcome

conveyor-bench is absorbed: the conveyor becomes the whole measurement loop — seed the SWE-bench subset, produce a patch per instance for an arm, run the graded test in a sandbox, parse the log with a ported swebench parser, resolve it, store the verdict, and compare runs. At the end, a 50-instance run is an ordinary tenant-scoped record with two controls that make its number publishable, and no Python exists in the build or the image.
