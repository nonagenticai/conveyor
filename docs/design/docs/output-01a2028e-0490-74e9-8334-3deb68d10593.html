Project brief — T4 Kanban coach (retrospective, 2026-11-22)

Outcome

The conveyor has a coach loop for an interruption. A failed run opens exactly one coach card with one triage and one remedy from the seeded closed catalogue; a repeat signature escalates instead of opening a second card; a failed coach run opens no coach card and a nested coach run is refused; and a systemic class starts kata.open. The first-interruption shape, escalation and the depth cap are live and proved by named tests; four findings remain open, and v1-p6-4 shows the 'exactly one' does not hold for a fourth distinct signature.

Boundary

T4 owns the interruption row, the coach card, its triage and remedy, the per-signature escalation rule and the depth cap. It does not own the board and pull path that calls err.card, the kata's own lifecycle and measurement (T5), the PM job (T3), operations incidents and postmortems (T7), or the tool platform (T13). T4 starts a kata process; it does not build the kata.
