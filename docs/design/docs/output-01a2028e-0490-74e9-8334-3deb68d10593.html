Project brief — T4 Kanban coach (retrospective, 2026-11-24)

Outcome

T4 is the kanban coach of the conveyor: an injected failure becomes exactly one coach card, one triage from a closed five-term set, and at most one remedy from a closed six-term set. A repeat signature inside the coach.window escalates through coach.escalation instead of opening a second card; a failed coach run never opens a coach card, so the coach chain settles at one card; and a systemic class opens one measured kata while a transient class opens none. The record claims the slice built (meta.measured_status: built) and issue #75 is closed, but the 2026-11-24 acceptance run is red on governance checks and this retrospective does not upgrade the claim to accepted.

Boundary

Out of scope: the kata lifecycle after open — observe, analyse, hypothesise, propose, measure, adopt — which belongs to T5 (issue #77); the board UI, which belongs to S12; card writes outside the action registry; and any second board, comment or membership store. The coach opens a kata but never adopts one: adoption is a human decision carrying evals:approve.
