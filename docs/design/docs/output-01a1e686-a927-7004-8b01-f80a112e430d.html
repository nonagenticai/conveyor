Evidence — S01 UI spike (retrospective, 2026-11-26)

Claim

The claim is that S01 decided the UI stack by measurement and recorded it as ADR 0001: Leptos CSR/WASM, because SSR lost on interaction TTI and the auth flow did not force cookie-based SSR. Eight metrics were to be taken per stack from building the board and the chat twice; five are complete, one is a single run, one was skipped and one is two runs. The project is closed and re-closes through the one gate. This evidence is retrospective and dated 2026-11-26.

Evidence

The record is ADR 0001 (docs/decisions/0001-ui-stack.md) with the measured table: interaction TTI CSR 5,426 ms (5,408–5,628) against SSR 5,736 ms (5,705–5,758), median n=5; 500-card first render CSR 4,726 ms against SSR 1,444 ms; bundle 290,723 B against 301,017 B gzip-9; drag p95 16.7 ms against 16.8 ms; auth passing on both stacks.
