Purpose, stakeholders and scope

Purpose. Give T19F one navigable set of decision, architecture, programme and delivery artefacts, each with an owner, a reviewer and a linked source, so the design gate and the tranche-6 review read the same record.

Stakeholders. The SRO, the BCM, the programme manager and architect, the Architecture Board, the departments that staff the board's seats, and the delivery teams that use the direct board path.

Scope. T19F only. T19's rows, T17's authoring assets and T9/T10's consumer rows are related sets, not part of this register.
