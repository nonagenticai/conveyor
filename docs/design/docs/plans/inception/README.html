Inception record — the five proposed V2 projects

This folder holds the durable inception artefacts for the five proposed V2 projects: T5 Kata, T6 Development project, T12 One organisation loop, T15 Tool authoring and BYO and T17 Tenant asset authoring.

All fifteen are published (2026-11-21) under the owner's direction in #527. The inception gate (crates/actions/src/programme.rs::assert_inception_published) is met for each project; this record authorises no tranche and claims no completion.

The standard

Each project carries the three categories its v2-proposed class declares in seed/output-standard.json:

File Category Required headings
00-project-brief.md project-brief Outcome, Boundary, Reuse sources, Inception units, Dependencies, Acceptance, Capabilities, Plan
01-inception-analysis.md inception-analysis Current state, Reuse sources, Build vs reuse, Risks
02-architecture-design.md architecture-design Context and boundary; Aggregates, tables and actions; Decisions; Acceptance; Architecture artefacts

Each file opens with the SPEC_V2 §8.1 common metadata (status, version, author/date, reviewer/review date, related project, rationale, published document/contract, phase/plateau, entries, links). Current-state rows cite path:symbol; every future claim is phrased as plan.

statement-of-architecture-work is not part of this set: it is a T9-only contract kind.

The live record

The bodies were written and independently reviewed under #347 (2026-11-18). That unit closed on publishable = true, while the inception gate reads published_at IS NOT NULL — so the documents were never actually published and the public index carried them as publishable drafts. This unit makes the bodies durable here, corrects the briefs, updates the live rows to the exact file bytes, and publishes all fifteen through documents.publish (2026-11-21). It also fixes the snapshot and outputs-index filters that treated publishable as publication.

Publication and what follows

  1. The bodies were reviewed independently under #347; the review defects are recorded on that issue.

Verification

  • Headings and metadata: the check in issue #527 (P1.1–P5.1).
  • Live bytes: documents.download must hash to the file's shasum -a 256.
  • Publication state: documents.get must read publishable = true, published_at non-null.
  • Public window: only published_at IS NOT NULL rows reach the snapshot and the outputs index (crates/store/src/snapshot.rs, crates/store/src/document.rs::list_published_outputs_tx).
  • No private host, path, token or credential appears in any file.
