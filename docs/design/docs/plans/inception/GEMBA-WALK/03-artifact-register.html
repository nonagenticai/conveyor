Common metadata

  • Status: draft; the Board's review date is 2026-12-03, after the P0 spike.
  • Version: 1; a change after approval is a new version and re-opens the gate.
  • Owner / reviewer / review date: per row above.
  • Purpose: give the client a typed architecture record that imports into the T9 repository.
  • Stakeholders and scope: the GEMBA-WALK project; no other project is changed.
  • Published document: this file and 02-architecture-design.md; live document ids are recorded at publication in the inception issue (#792).

Review

The programme architect owns the register; the Architecture Board reviews the set after the P0 spike and records one compliance level per review. A deviation is a change request, never a silent fork. The register is imported as typed architecture_artifact rows at publication; no row here is approved before the Board sits.
