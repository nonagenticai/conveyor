src/tenant.rs Tenant(Uuid), new, parse, id, FromStr, resolve_tenant(scope: Option<TokenScope>, asked: Option<Tenant>) Newtype validated at construction; resolve_tenant makes the token scope win over any requested tenant and errors on mismatch. Carry the newtype and the precedence rule — authenticated scope beats a requested tenant, disagreement is an error. CONTRACT §9's concrete shape. A pub field gives back the invalid state the type prevents. parse rejecting nil matters: nil is a valid Postgres uuid that matches nothing, silently.
src/store_providers.rs is_empty(conn, store), check_retag, put_store_providers_tx(...) The _tx convention — takes a connection, opens no transaction of its own, so the caller composes. check_retag is a precondition read in the same tx as the write. Carry the _tx naming, absolutely (claim_card_tx): it makes "does this commit?" answerable at the call site. One _tx method that calls db.begin() internally deadlocks against the caller's open tx on the same row.
src/metrics.rs METRICS_PATH, handle() -> &'static PrometheusHandle (OnceLock), describe(), RequestCtx, record_stages, LATENCY_BUCKETS, OUTBOX_COUNT_TIMEOUT 1 s One OnceLock handle; a per-request context accumulates timings and emits once, so instrumentation is one object passed down. Carry the OnceLock handle, per-request context, explicit buckets, and a timeout on any gauge that queries the DB. A DB-querying scrape endpoint without a timeout turns a slow database into "service down" while it serves fine — hence OUTBOX_COUNT_TIMEOUT.
tests/common/mod.rs TestDb, Server, IMAGE = "pgvector/pgvector", TAG = "0.8.7-pg18", SERVER: OnceCell, CONTAINER_ID: OnceLock, remove_shared_container() (atexit) One container per test binary, one fresh database per test; TEST_DATABASE_URL short-circuits. The handle sits in a static so Rust never drops it — removal is an atexit hook shelling docker rm -f -v by recorded id, with retries under a unique name. Carry the whole pattern. The template's per-run container is the degenerate case. Three measured traps: (1) Drop never runs for a static, so without atexit every run leaks a container; (2) per-test containers spawn dozens of concurrent docker runs and overload the Docker VM; (3) a container that fails to start is unreachable by handle — only the recorded name cleans it up.
