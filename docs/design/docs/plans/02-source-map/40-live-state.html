What this changes in the SPEC

§9 assumed (1) ingress logs answer per-path usage, (2) n8n execution data answers which operations ran, (3) the Planka feature table is a usage source. Measured: (1) is a 24-hour sample, (2) is a 3-day sample, (3) is test data. S0 must therefore rank evidence: flow JSON + code call sites (durable) > 24 h Loki sample > execution sample > row counts, and mark every used verdict with the evidence class that produced it.
