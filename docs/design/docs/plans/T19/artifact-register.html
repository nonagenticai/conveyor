Purpose, stakeholders and scope

Purpose. Give the T19 project one navigable set of decision, architecture, programme and delivery artefacts, each with an owner, a reviewer and a linked source, so the design gate and the tranche review read the same record.

Stakeholders. The sponsoring group/SRO, the BCM, the programme manager and architect, the Architecture Board, the departments that staff meeting seats, and the delivery team.

Scope. T19 only; the T18 UI lane, the T9 repository rows and the T10 cadence rows are consumers or related sets, not part of this register.

Review

The set is reviewed together on 2026-11-30. An artefact missing its owner, reviewer, review date or document is refused at the review; an approved artefact is superseded, never edited in place. The future T9 import maps each row to architecture_artifact + architecture_artifact_entry + architecture_artifact_link; the document becomes the published body.
