Benefit profile — B4 Public collaboration

Identification and purpose

Reference B4. Category: strategic. Description: An outside reader can read every published output, and an outside issue or PR changes the design.

Objectives: O6 The public can see and challenge the design. Observable outcome: the improvement is visible in an outside issue or PR that changes a published output; every published output has a stable URL and a discussion link.

Performance

Affected KPIs: an outside issue or PR that changes a published output; every published output has a stable URL and a discussion link.

Baseline: not measured. No instrument records the old practice, so the profile states the baseline honestly; the measurement is recorded as kata 01a1e9df-d36f-77f7-8b24-8dab7b92a855 and the profile is updated when it is taken (P0 plan §6: a benefit whose baseline was never measured cannot claim an improvement).

Target: at least one outside contribution changes a published output; every output is reachable. Measurement method: The GitHub issue registry and merged PR authors; the publications are recorded on the programme issues.

Financial value: not expressible at this baseline; it follows from the measured baseline and is set by the sponsor at acceptance.

Cost

the site's maintenance and review time, including the business change the benefit depends on.

Conditions

Capability required: The public design site and the contribution path (issue forms, DCO, CONTRIBUTING). Preconditions: the public repository; the published output set.

Uncertainty and dependencies

Risks and issues: unreviewed public input or spam. The enabling project is DESIGN-PUBLISH; a slip there puts this benefit at risk through the benefits map.

Responsibility and attribution

Owner: programme manager (interim); the BCM position is unstaffed. Operational area: the conveyor programme. The benefit row is 01a1e9df-1592-79a5-839e-037d8fe4251b; the BCM attribution is a visible gap until the position is staffed (the skills assessment records it), and the programme manager is the interim accountable owner.
