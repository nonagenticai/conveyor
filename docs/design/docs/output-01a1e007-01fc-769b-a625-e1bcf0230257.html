The outcome is one sentence about what is true after the project; the boundary states what is out of scope and which existing surfaces must not be forked; dependencies are typed as blocked-by, acceptance-blocked-by, blocks or related.

Inception units

Every delivery project's first two claims are analysis and architecture. Analysis inventories the code that already exists inside the repository, in the wider estate and upstream, with contract and licence constraints and the build-versus-reuse decision. Architecture is produced to the artefact standard of SPEC_V2 §8.1 and carries the typed artefacts its phase and plateau require. Both are published when accepted, and a project without both is an inception gap whose build units are not claimed.
