Categories

The seven Architecture Skills Framework categories:

  1. General — communication, leadership, teamwork, decision-making.
  2. Business skills and methods — strategy, benefits, operating models, process.
  3. Architecture skills — the ADM, modelling, artefact production, architecture governance.
  4. Programme and project management — planning, tranches, risk, quality, delivery control.
  5. General IT knowledge — systems, data, networking, operations, security fundamentals.
  6. Technical IT skills — software engineering, languages, databases, platforms, testing.
  7. Legal environment — licensing, contracts, data protection, procurement.

Proficiency is scored 0–5: 0 none, 1 aware, 2 developing practitioner, 3 practitioner, 4 advanced practitioner, 5 expert. A rating names its evidence; an unstaffed role is none (0) and is recorded as a gap, not a zero score to be argued away.
