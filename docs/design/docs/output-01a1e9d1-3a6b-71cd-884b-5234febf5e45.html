Architecture skills assessment — P0 (retrospective, 2026-11-26)

Categories

The assessment published on 2026-11-18 at 08:18:18 (01a1e9d1-3a6b-71cd-884b-5234febf5e45) scores seven architecture skill categories, as plan §3 item 14 requires of the architecture capability baseline. The categories are the programme's capability view of the people the delivery tranches need, and they sit beside the nine-dimension maturity assessment in the same baseline.

Proficiency by role

The assessment records proficiency by role, so the gap between the architect, programme manager, BCM, SRO and the other programme positions is visible per category rather than averaged. That matters because SPEC_V2 §8.3 makes roles positions with authority rows: a role without the proficiency is a staffing risk, not a modelling problem. The P0 record defines the matrix; it does not claim any role has been filled or developed.

Baseline

The baseline is the measured starting proficiency, taken with the definition set rather than after the first delivery tranche. It is the reference the development milestones are measured against, and it is not a statement that the programme is sufficiently skilled. No re-assessment has been recorded for 2026-11-26, so the baseline remains the only measurement.

Development milestones

The assessment records development milestones for the seven categories, which the programme manages as the delivery tranches run. The milestones are part of the published baseline; their completion is not claimed by P0, and no training, recruitment or certification is recorded as delivered. That is the honest boundary between defining the capability baseline and building the capability.
