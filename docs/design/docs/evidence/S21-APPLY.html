S21 step 5 — the applying gate (issue #590)

Status: in flight, 2026-11-22. This receipt is filled at the PR head; the tables below are the scenario map, not results.

What changes

  • A handover parks the run in waiting_approval; the executor approval names the draft.
  • approvals.decide records the L3 gate.draft_apply decision, settles the run running and enqueues run.resume.
  • run.resume applies the draft through the one helper and finishes the run; it never calls the model.
  • ladder.record refuses a forged human rung; ladder.apply_draft requires the decision to name the draft (rework v1-w1c-2:T2).
