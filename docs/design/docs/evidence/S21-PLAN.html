Deep audit (fresh agent, read-only) — dispositions

Verdict on the first pass: NO, five findings. Dispositions:

  1. Fixed — a present-but-non-string meta.expires_at was silently treated as absent. The publish mapping now records it for GateNeverOpens, and an actions test inserts a numeric-expiry gate row and proves the 422. ⚠️ The FIRST version of this check also refused a valid PAST timestamp; the workspace suite caught that as a false positive — procedure_step's an_expired_gate_applies_the_steps_on_error publishes such a procedure deliberately and proves the runtime applies the step's on_error. The check now refuses only an expiry the runtime cannot read, and the suite test passes.
  2. Answered, documented — allOf is unioned, not intersected. The walker is a declared-path reader, not a JSON-Schema validator; a flattened schemars object adds members in a second branch. The semantics are stated at schema_has_path.
  3. Fixed — the projection did not reject a self/forward reference on its own. It now emits FutureInput, with a test covering both (the template error still wins at publish).
  4. Fixed — an external $ref was false-refused; it now does not refuse a declaration it cannot read.
  5. Answered — the steps.N.output fixtures are WORKFLOW definitions validated by conveyor_workflow::definition::validate_publish, not procedures, so they are unaffected. The real consequence (an existing procedure DRAFT must declare its outputs before republishing) is deliberate and stated in the migration comment.

Second fresh audit: PASS. It verified the five dispositions and returned PASS with three non-blocking findings; two were taken as hardening: a cyclic $ref (root # or a self-referential $defs entry) recursed without consuming a segment — now capped at 64 hops and refused; and a steps. reference whose index is not a positive integer was silently dropped — now BadInputReference. The third (a FutureInput also raises UnreachableStep) is the intended summary shape.
