Tolerances

The captured error envelopes carry request_id (ULID) and timestamp, and compile_submit carries a minted job_id and poll_url. Those are the only fields that cannot replay; the parity table names each, and everything else in a golden is compared exactly.

What the rewrite does

The reference answered 202 and rendered asynchronously behind a lease and a reaper. The executor does the work inside one job: inputs arrive as files in the work directory, the encoded master leaves as a declared output through conveyor's own upload route. Anything the reference offered that this port does not (grading, caption burn-in, ambient audio bed, cursor/focus tracks) is refused by name with a stable code — never accepted and ignored.
