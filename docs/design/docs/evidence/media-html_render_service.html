Traps worth keeping

  • This service reads API_PORT, not PORT; the rig exports the latter.
  • A non-UUID X-Tenant-Id is refused exactly like a missing one (TENANT_REQUIRED), so a capture case that "tests a bad tenant" is really testing the same 401.
  • PDF bytes are nondeterministic (/CreationDate, /ID inside the document), so the golden is compared by invariants (page count, text extraction, size band), not byte equality.

What the rewrite does

One capability: an HTML document in, a PDF or PNG out, driven by the image's own Chromium. The Playwright wait_until vocabulary has no headless equivalent and is refused by name (wait_until_not_supported) with wait_ms as the substitute — a declared gap, not a silent one.
