The coding path

The external action itself (coding_jobs.create) is refused by the admin CLI with "not an internal action" (12-coding-direct.stderr). That is the design: an external action is dispatched by the broker, so the real contract is tools.call, which resolves the run's binding, pins the published toolkit version, validates the input, owns the deadline and ledgers the call.

What is not claimed
