Build vs reuse

  • Metrics and metering: build read models in crates/actions over existing tables. No Prometheus, Grafana or time-series store, no new service (blueprint; D37).
  • Billing: reuse the charging system, build only reconciliation; reads stay the declared external action and nothing writes to billing.
  • Quality: reuse the eval and benchmark rows and report actions; T11 aggregates and never redefines an instrument (§9.3).
  • Maturity: build versioned thresholds and evidence-bearing assessments; do not reuse T9's nine-dimension architecture_maturity.
  • Price history: build a versioned price table, because commercial_price keeps one row per model and a price edit would rewrite past cost.
  • Licence/contract: workspace crates only; public repo, so no private host, path or credential enters code or output; no new port (8930).

Risks

  • Stored metrics drift into opinion → check: rg -n 'metrics\.' docs/design/data/actions.json and a recompute-twice test that writes nothing.
  • Double counting across conveyor, router and eval calls → check: every bucket sums to the tenant call count; unattributed calls reported separately.
  • Unpriced models rendered as free → check: rg -n 'unpriced' migrations/0045_commercial_price.sql and an explicit unpriced bucket.
  • Department joins multiplying rows → check: a partitioned-sum invariant over department.
  • Period or clock skew with billing → a false incident → check: fixed UTC day boundaries and a pinned-period test.
  • A zero-traffic gate flagged as broken → check: a minimum sample read from configuration.
  • Maturity churn on unchanged evidence → check: evidence hash and threshold version on every assessment.

Open questions

  1. Does reconciliation compare tokens, money, or both, and over which boundary?
  2. Which refusal source counts for the never-refused flag: audit_event.status='refused' directly, or a dedicated gate-refusal event derived from it?
  3. Which level owns "programme" when a project belongs to several? T11 must not invent an allocation.
  4. One C0–C5 level per family or one organisational level, and who calibrates the first thresholds?
  5. Does tool-spend metering wait for T13 (#76), and is it reported as unavailable, not zero, until then?
  6. Per tenant-day or per billing cycle, and who owns the incident reconciliation opens?
