Current state

Built. industry, job_catalogue, job_department, job_release and job_binding exist with RLS and version columns (migrations/0040_organisation.sql:job_catalogue, migrations/0040_organisation.sql:job_release, migrations/0040_organisation.sql:job_binding); department predates them (migrations/0001_platform.sql:department). The release hash is canonical (crates/domain/src/organisation.rs:release_hash), and a binding copies hash and snapshot, so a changed release is a new binding rather than an edit.

Built. job_catalogue.create/update/retire/get/list (crates/actions/src/organisation.rs:job_catalogue_create), job_releases.publish/retire (crates/actions/src/organisation.rs:job_releases_publish), departments (crates/actions/src/handlers.rs:departments_create), industries and job bindings all appear in docs/design/data/actions.json.

Built, not wired to assets. approval_policy holds one tenant-scoped decision per action with approval ∈ required|waived and self_approval ∈ forbidden|allowed, defaulting to forbidden (migrations/0050_approval_policies.sql:approval_policy); crates/actions/src/control/policies.rs:approval_policies_set writes it and crates/actions/src/control/approvals.rs:approvals_request opens a gate. No asset publication uses them.

Built. seed/organisation.json transcribes industries, departments and jobs from SPEC §4.6 as seed rows, not tenant-authored ones.

Absent — publication. No action can publish an authored asset: docs/design/data/actions.json has zero authoring.* names and crates/actions/src/ has no authoring module. A stale binding refuses 409 job_binding_stale; binding_required (409) and a missing binding are also served (crates/actions/src/control/mod.rs).

Partial. documents.ingest hands one document to the knowledge service (crates/actions/src/documents/ingest.rs:documents_ingest) — an intake seam, not a converter; it writes no draft. governed_asset's kind CHECK was widened by migrations/0044_plan_spine.sql:governed_asset to admit the §10.3 kinds including sop_source; what the table cannot carry is a typed organisation, procedure or policy target. The executable procedure tables were renamed by migrations/0035_process_tree.sql:process (procedure → process, procedure_step → process_step), and that migration's new procedure (migrations/0035_process_tree.sql:procedure) is the SOP text; neither carries PDDL text or a PKO pin.

Absent — hard dependencies. T16 (#85, OPEN status:blocked): no pko_release/pko_entity/pko_relation in migrations/ and no procedures.ingest_sop|draft action, so the conversion path T17 generalises does not exist. T13 (#76, OPEN status:claimed): no tool/toolkit/tool_binding/tool_call table, so a tool request has no target and no ceiling to check. T3 is present as migrations/0049_pm_job.sql and crates/actions/src/pm/; its acceptance is outside this unit.

Planned — this unit. T17 (#87) is OPEN status:blocked; this is inception work, not build evidence.
