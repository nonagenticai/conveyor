Claim

S02 delivered the conveyor skeleton: a ten-member Rust workspace and one conveyor binary over Postgres 18 with eleven platform tables under forced RLS, OIDC and dev authentication, a fail-closed app_licence gate, a fenced job runner and a replaying SSE stream; the S2 gate is two tenants isolated including RLS, and login works.

Evidence

  • migrations/0001_platform.sql: exactly the eleven tables tenant, app_user, department, membership, event, job, schedule, audit_event, action_invocation, idempotency_key and app_licence. The nine tenant-owned tables are ENABLE + FORCE ROW LEVEL SECURITY with one tenant_isolation FOR ALL policy carrying USING and WITH CHECK; membership_self_read is SELECT-only TO conveyor_runtime; audit_event loses UPDATE and DELETE after the schema-wide grant.
  • crates/store/src/scope.rs: begin_scoped sets app.current_tenant with set_config($1, $2, true); a session-level SET is never used.
  • crates/store/src/jobs.rs: claim is FOR UPDATE SKIP LOCKED with lease_token/lease_until; DEFAULT_LEASE_SECS = 60; expired leases are reclaimed and attempts increments; every finish/retry is guarded by status = 'running' AND lease_token = $token; exhausted rows go dead.
  • crates/store/src/schedule.rs: materialisation takes pg_advisory_xact_lock(hashtext('conveyor:schedule')) first.
  • crates/auth/src/jwks.rs: JWKS_TTL = 600 s, JWKS_MIN_REFRESH = 30 s, required aud and azp; crates/auth/src/dev.rs resolves dev:<login> through membership.
  • crates/auth/src/licence.rs: LICENCE_MAX_AGE_SECS = 3600; absent, stale, expired, revoked and unknown statuses all refuse; app_licence is the only source.
  • crates/api/src/routes/events.rs: Last-Event-ID is event.seq; replay is seq > $last AND topic = ANY($topics) ORDER BY seq LIMIT 500 in tenant scope; keepalive 15 s; a 64-slot channel closes a slow client with resync.
  • Tests present in the tree: apps/server/tests/rls.rs (runtime role, owner negative control, superuser positive control), apps/server/tests/jobs_kill.rs (JOB_LEASE_SECS=2, SIGKILL, reclaim, stale token writes nothing) and apps/server/tests/events.rs (replay ordering, tenant filtering, doorbell, resync, licence gate).
