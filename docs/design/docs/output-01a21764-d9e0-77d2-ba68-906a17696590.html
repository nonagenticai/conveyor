Architecture Artefact Index — PLATFORM

Metadata

This index names the fifteen typed artefacts the platform's programme-track architecture set carries, their phases and plateaus, and the document that publishes each. It is the entry point the Architecture Board reads before the artefacts themselves; the artefacts are the rows, the index is their map.

Entries

The set runs from Phase A's stakeholder map, driver catalog, requirements catalog and solution concept diagram through Phase B's capability map, Phase C's data catalog and Phase D's technology standards, then Phase E's gap matrix, candidate solutions, context diagram and benefits diagram, Phase F's migration plan, Phase G's compliance review catalog and Phase H's change and requirement catalogs. Each entry names its artefact row and its published document.

Links

Every artefact links to at least one other: the requirements to the drivers, the capability map to the solution concept, the gap matrix to the capability map and standards, the migration plan to the candidates, standards, gaps and benefits, and the Phase H catalogs to the reviews and the requirements. The graph is the derivation the board inspects.

Document

The index is itself an artefact document: the published body the architecture repository reads alongside the typed rows. A reader who needs the platform's architecture starts here and follows the links; a reader who needs one artefact reads its own document. The index never duplicates an artefact's content, it points.
