Build vs reuse

The eleven architecture tables are built, because §10.3 gives an architecture artefact and its contract their own tables and governed_asset.kind is explicitly not widened for them (plan §6). ArchiMate modelling, a live metamodel and a diagram renderer are out of scope: a diagram is a document with typed metadata and a viewpoint (§8.6).

Each is an open ledger finding, not a hypothetical.
