Project Brief — S04 Action registry (retrospective, 2026-11-26)

Outcome

One declaration per invocable operation, projected into the manifest, the OpenAPI document, the MCP tool list and the router, so HTTP and MCP cannot diverge. The slice's gate is twenty actions identical over HTTP and MCP, proved by the parity test over the sixteen internal and four fixtures.* external actions, with one spec_hash across all four projections.

Boundary

In: the ActionSpec declaration and #[action] derive, the compile-time registry and its boot assertion, GET /api/actions, POST /api/actions/{name}/invocations with idempotency, deadline, audit and transaction, rmcp at /mcp, the OpenAPI fold and lock, the openapiv3 ingest, and migrations/0003_action_registry.sql. Out: domain actions (S05–S11), workflow execution (S13), channel-mcp delivery rows (S06) and the signed mcp_server channel (S06-α).

Reuse sources

The fr registry's Capability field set and generation approach; the agent runtime catalog's OpDef, PinnedCatalog::from_rows, effective_level and outputs. The slice carries the field set and the closed effect/confirm/tenancy vocabularies, not Zod, not a legacy handler.

Inception units

The sixteen internal actions and the four external fixtures, the invocation path, the manifest and MCP projections, the OpenAPI fold and lock, the ingest diff and the boot assertion — the work packages recorded in the project WBS.

Dependencies

S02 supplies the tenancy, audit and idempotency spine; S03 the domain aggregates and transitions the domain actions build on. Every later slice adds actions through this registry, never a surface.

Acceptance

cargo test -p conveyor-actions over the parity, invocation, idempotency, ingest, timeout and runtime-resolution targets; the served lock check exits 0; a duplicate registration exits 1 before bind; schema-invalid input returns RFC 9457 with populated errors[]; and the imported action round trip serves over HTTP and MCP across a restart.

Capabilities

Action declaration and projection, a fail-closed registry, idempotent invocation, external action ingest under the same contract, contained outbound failures, MCP parity and the OpenAPI lock.
