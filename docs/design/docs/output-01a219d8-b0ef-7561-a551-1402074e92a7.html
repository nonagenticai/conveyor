Project brief — S05 Board (retrospective, 2026-11-24)

Outcome

S05 is the board slice: project → board → list → card plus labels, comments, tasks, custom fields, board membership and webhook subscriptions, on one action registry, one comment store, one membership model and one outbox, so that the 280 board↔project lookup flows become one foreign-key read through the project_type matrix and domain::board::may_move. The record claims the slice built (meta.measured_status: built); the acceptance gate is not evidenced at the snapshot, and this rework records that rather than claiming a pass.

Boundary

Out of scope: attachments and card-level memberships (never a table, route or action), claims, assignee and stopwatch writes (S06), webhook delivery rows as actions (they are jobs), and the UI (S12). Acceptance

The slice gate: replay a board export, win a two-client race and survive the 1k-card load. The six properties are (a) replay fidelity — 1,000 cards/10 lists with zero deltas; (b) one winner — one 200 and one 412 with the current representation; (c) 1k load — p95 ≤ 120 ms at 20 rps, 1,000 cards in five pages ≤ 500 ms; (d) webhook shape — {event,data,prevData,user} exactly; (e) SSE — card.moved ≤ 200 ms live and on replay; (f) no second store. The commands are the four CLI subcommands, the k6 script and the four test binaries in plan §7. The instrument is acceptance/programme/S05.toml.
