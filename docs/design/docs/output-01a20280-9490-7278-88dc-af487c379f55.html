Project brief — T9 TOGAF ADM capability (retrospective, 2026-11-22)

Outcome

The conveyor has an architecture capability, not a document library. The Preliminary phase establishes the typed artefact standard and repository, the tailored adm_profile, the Architecture Board, the four contract kinds, the compliance review and waiver register, and the nine-dimension maturity and seven-category skills assessments. An architecture project walks Preliminary and A–H as WBS nodes, each phase closing on an approved contract once its mandatory artefacts are approved; a delivery project is refused at design without a live contract. Six P1/P2 findings remain open, and the Phase-H exactly-one clause is not proved.
