# Identity: every authenticated case carries `X-Tenant-Id: Bearer <opaque>` — the licence-credential
# shape the orchestrator sends. The capture rig points LICENSE_INTROSPECT_URL at a local stub whose
# answer is ONE active licence (tenant 00000000-0000-0000-0000-0000000000c1, subject
# 00000000-0000-0000-0000-0000000000a1, the latter listed in AUTH_DELEGATING_SUBJECTS). The licence
# lane therefore runs for real, and the app's orchestrator-SA gate is satisfied without a cluster.
# `/api/upload*`, `/api/settings*` and `/api/auth/*` additionally demand the real caller tenant in
# `X-Owner-Tenant-Id`, honoured only from that service account. `/api/admin/*` is the mirror image:
# it REFUSES `X-Owner-Tenant-Id` (403 "operator routes are not owner-tenant scoped"), so the admin
# cases carry the licence credential only.
#
# Order is load-bearing: the empty job list is captured before `upload_submit` creates a job, and
# `auth_connect` is captured before `settings_put` stores an OAuth client (connect would embed its
# client_id). The scratch database must be freshly migrated for each capture.
