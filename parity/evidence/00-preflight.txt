      set that rewrites literal names ('/api/tools/n8n/...' -> '/api/tools/n:idn/...') and path
      parameters ('{v1}' -> '{v:id}'). The prose requirement is "UUID/number SEGMENTS -> :id", so
      normalisation was applied segment-wise (a whole segment that is a UUID or all-digits becomes
      :id). No route surface in this inventory contained such a segment; the rule is applied for
      determinism and n8n tuple names are untouched.
   b) Matching: a concrete request path is matched to a surface template by splitting both on '/',
      treating {param}/:param segments as one-segment wildcards and (.*) as a suffix wildcard.
      Trailing-slash variants are accepted because FastAPI/Nest issue 307s between /x and /x/.

      in principle make arbitrary HTTP calls; no n8n-nodes-base.httpRequest node exists in any flow
      (George 2026-11-04: no plain HTTP nodes), so this is not expected, but it is UNMEASURED.
